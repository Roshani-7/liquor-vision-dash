# Sales Intelligence System

Create a modern, advanced web application called "Sales Intelligence System" for an Area Sales Manager in the liquor industry.

Design:

- Clean, professional dashboard

- Mobile-first responsive UI

- Sidebar navigation + top navbar

- Dark/light mode

Core Features:

1. Smart Dashboard:

- Show total sales (daily, weekly, monthly)

- Target vs achievement with percentage

- Highlight:

  - Underperforming areas

  - Top-performing shops

- Charts:

  - Sales trends (line chart)

  - Area performance (bar chart)

  - Shop contribution (pie chart)

2. Distributor Management:

- Add/edit/delete shops

- Fields: name, area, category, contact

- Show last visit and last order

- Auto classify shops (high/medium/low performance)

3. Sales Entry System:

- Add daily sales data

- Auto-calculate totals

- Link sales to shops and products

4. Intelligent Order Management:

- Track orders with status (pending, approved, delivered)

- Alert for delayed orders

- Suggest repeat orders based on past data

5. Smart Visit Planner:

- Suggest daily shop visits based on:

  - low sales

  - long time since last visit

  - pending issues

6. Target Management:

- Monthly, weekly, daily targets

- Show required daily sales to achieve goal

7. Advanced Analytics:

- Area-wise comparison

- Product-wise sales performance

- Growth trends

8. Reports:

- Generate daily, weekly, monthly reports

- Export as PDF

9. Notifications:

- Low sales alerts

- Target warnings

- Pending order alerts

Technical:

- Frontend: React or HTML/CSS/JS

- Backend: Firebase (Authentication + Firestore)

- Use Chart.js for graphs

- Clean, modular code

Goal:

Build a powerful yet simple system that reduces manual work, improves decision-making, and helps the sales manager manage distributors, sales, visits, and performance efficiently.
